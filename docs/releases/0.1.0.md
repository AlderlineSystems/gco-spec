# gco-spec 0.1.0

Released 2026-09-21.

`gco-spec` is the reference Python implementation of the Governance Context
Object (GCO) from the in-repo position paper
[The Recursion Blindspot](../../recursion-blindspot-v5.md). It ships attested
parent-child tightening, `GovernanceRuntime` authorization, a tamper-evident
policy deployment ledger, and a P0 MCP `_meta` adapter.

It is an authority-propagation primitive. It does not inspect action content,
revoke attestations, isolate hosts, provide multi-writer ledger consensus, or
implement MCP tasks, handles, or SEP.

Cite git tag `v0.1.0` until a PyPI package exists. Install from that tag or
from the GitHub Release:

```bash
python -m pip install "gco-spec @ git+https://github.com/SSBrouhard/gco-spec.git@v0.1.0"
```
